# CodexMeter v0.4.2

CodexMeter 0.4.2 prevents release builds from appearing as a second installed app in macOS search.

## Highlights

- Release packaging unregisters and removes its temporary `build/CodexMeter.app` after the verified archive is created.
- Caller-provided app bundles remain untouched.

## Install

On an Apple Silicon Mac:

```bash
curl -fsSL https://raw.githubusercontent.com/LAwLi3tCoding/CodexMeter/main/scripts/install.sh | zsh
```

The installer verifies the published SHA-256 checksum and app signature before installation. Release binaries are ad-hoc signed and are not notarized with an Apple Developer ID.

## Compatibility

- macOS 13 Ventura or later.
- Apple Silicon (`arm64`) Release binary.
- A locally installed and signed-in Codex CLI.
