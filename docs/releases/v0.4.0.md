# CodexMeter v0.4.0

CodexMeter 0.4.0 adds a compact local usage dashboard alongside the existing Codex quota view.

## Highlights

- View exactly 30 local-calendar days of Token usage in a native bar chart.
- Hover any bar to see the date, exact Token count, and API-equivalent USD estimate.
- Compare the latest available day, 7-day, and 30-day Token totals.
- See the current configured model and the most-used model across threads started in the last seven days.
- Track seven-day pace, peak day, and current usage streak.
- Keep quota and usage refreshes isolated so a failure in one source does not hide valid data from the other.
- Retain the last successful usage update during temporary refresh failures.
- Configure an optional credential-free loopback HTTP(S) proxy for local Codex App Server connectivity.
- Refined compact layout, including smaller weekly quota and summary sections, exact chart hover details, and an orange-red streak badge.

## Install

On an Apple Silicon Mac:

```bash
curl -fsSL https://raw.githubusercontent.com/LAwLi3tCoding/CodexMeter/main/scripts/install.sh | zsh
```

The installer verifies the published SHA-256 checksum and app signature before installation. Release binaries are ad-hoc signed and are not notarized with an Apple Developer ID.

## Compatibility

- macOS 13 Ventura or later.
- Apple Silicon (`arm64`) Release binary.
- A locally installed and signed-in Codex CLI whose App Server exposes quota and usage read methods.

USD values are API-equivalent estimates based on the current configured model, not invoices or subscription charges.
